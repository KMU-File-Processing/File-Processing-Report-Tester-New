# 화일처리 모의 채점기

BST / AVL / B-Tree 과제를 제출 전에 미리 돌려볼 수 있는 채점기입니다.
공개 테스트케이스 20개로 검사하고, 틀린 케이스가 있으면 어느 줄이 어떻게 다른지 보여줍니다.

점수는 나오지 않고 케이스별 통과 여부만 확인할 수 있습니다.

---

## Windows

1. [Releases](../../releases)에서 `FP-Tester.exe`를 내려받습니다.
2. 더블클릭하면 콘솔 창이 뜨고 브라우저가 열립니다.
3. 과제를 고르고 **찾기**로 소스 파일(`.c`/`.cpp`)을 선택한 다음 **테스트 실행**을 누릅니다.
   경로를 직접 입력해도 됩니다.

> **"Windows에서 PC를 보호했습니다" 창이 뜨는 경우**
> 코드 서명이 없는 프로그램이라 표시되는 경고입니다.
> **추가 정보** → **실행**을 누르면 실행됩니다.
> 백신 프로그램이 차단한다면 예외로 등록하거나, 아래 방법대로 소스로 실행하면 됩니다.

## macOS, Linux 또는 exe가 실행되지 않을 때

[Python 3.10 이상](https://www.python.org/downloads/)이 설치되어 있으면 소스로 바로 실행할 수 있습니다.

```bash
git clone <이 저장소 주소>
cd <저장소 폴더>
python app.py
```

실행하면 브라우저가 자동으로 열립니다. 열리지 않으면 터미널에 출력된 주소로 직접 접속하세요.

실행 파일이 필요하면 `python build_tester.py`로 사용 중인 OS용 실행 파일을 만들 수 있습니다.
(Windows에서는 `build_tester.bat`을 더블클릭해도 됩니다.) 소스로 잘 실행된다면 따로 만들 필요는 없습니다.

## 준비물

C/C++ 컴파일러가 설치되어 있어야 합니다. 설치되어 있으면 채점기가 자동으로 찾습니다.

| OS | 설치 방법 |
|---|---|
| Windows | [MSYS2](https://www.msys2.org/) 설치 후 `pacman -S mingw-w64-ucrt-x86_64-gcc` |
| macOS | 터미널에서 `xcode-select --install` |
| Linux | `sudo apt install g++` |

- GCC 7 이상 또는 Clang 5 이상이 필요합니다. Visual Studio의 MSVC(`cl.exe`)는 지원하지 않습니다.
- PATH에 등록되어 있거나 MSYS2·LLVM 기본 경로에 설치되어 있으면 자동으로 찾습니다.
- CLion에 포함된 MinGW는 자동으로 찾지 못하므로, 해당 `bin` 폴더를 PATH에 추가하거나 위 표대로 MSYS2를 설치하세요.

## 채점 환경

| 항목 | 내용 |
|---|---|
| 제출 파일 | `.c`, `.cpp`, `.cc`, `.cxx` 중 하나 |
| 입력 | 표준 입력(stdin)으로 전달 |
| 출력 | 표준 출력(stdout)으로 출력된 내용을 정답과 비교 |
| 시간 제한 | 케이스당 5초 |
| 컴파일 옵션 | `-std=c++17 -O0 -g` (C 파일은 컴파일러 기본 표준) |
| 경고 검사 | `-Wall -Wextra -Werror` |

C++17로 컴파일되지 않으면 C++20, C++14 순서로 다시 시도합니다.
경고 검사 결과는 케이스 통과 여부에는 영향을 주지 않고, 화면에 "컴파일 경고 있음/없음"으로만 표시됩니다.

## 결과 보는 법

```
18 / 20        컴파일 경고 없음        메모리 누수 없음
```

케이스 번호를 누르면 해당 케이스의 결과를 볼 수 있습니다.

| 색 | 의미 |
|---|---|
| 초록 | 통과 |
| 빨강 | 출력 불일치, 시간 초과, 비정상 종료 |

틀린 케이스는 **처음으로 달라지는 줄**을 표시합니다.

```
41   << 3 > 7 < 12 >>
42 − << 3 > 7 << 9 > 12 >>     내 출력
42 + << 3 < 5 >> 7 < 12 >>     정답
43   ...
```

**입력 복사**를 누르면 해당 케이스의 입력이 클립보드에 복사됩니다.
IDE나 터미널에 붙여넣어 직접 디버깅할 때 사용하세요.

## 자주 묻는 질문

**컴파일러를 찾을 수 없다고 나와요:**
위 표를 참고해 컴파일러를 설치한 뒤 채점기를 다시 실행하세요.

**컴파일은 되는데 모든 케이스가 틀려요:**
먼저 입력을 표준 입력으로 읽고 있는지 확인하세요.
그다음 출력 형식을 확인하세요. 공백 하나까지 정확히 같아야 합니다.
`< 25 < 500 >>`처럼 노드 사이 공백과 꺾쇠 위치가 과제 명세와 같아야 합니다.

**시간 초과가 나요:**
케이스 하나가 5초 안에 끝나지 않으면 시간 초과입니다. 대부분 무한 루프가 원인입니다. 삭제할 때 부모 포인터를 갱신하지 않아
트리에 사이클이 생기는 경우가 많습니다.

**메모리 누수가 있다고 나와요:**
프로그램이 종료되기 전에 트리의 모든 노드를 해제해야 합니다.
`delete`가 빠진 경로가 없는지 확인하세요.

**그 밖의 문제:**
아래 명령으로 실행 환경과 컴파일러 상태를 점검할 수 있습니다.

```
FP-Tester.exe --diagnose
```

소스로 실행하는 경우에는 `python diagnose.py`를 실행하면 됩니다.

## 참고

- 이 채점기는 **공개 테스트케이스**만 사용합니다. 실제 채점에는 더 많은 케이스가
  사용되므로, 여기서 모두 통과해도 만점이 보장되지는 않습니다.
- 반대로 여기서 틀린 케이스는 실제 채점에서도 틀립니다. 제출 전에 꼭 확인하세요.
- 채점은 모두 본인 PC에서 이루어지며, 외부로 전송되는 데이터는 없습니다.
