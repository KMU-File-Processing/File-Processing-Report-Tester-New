# 화일처리 모의 채점기

BST / AVL / B-Tree 과제를 제출하기 전에 직접 돌려볼 수 있는 채점기입니다.
공개 테스트케이스 20개로 검사하고, 틀린 케이스는 어디서 어떻게 다른지 보여줍니다.

실제 채점 점수는 알려주지 않습니다. 통과 여부만 확인하는 도구입니다.

---

## Windows

1. [Releases](../../releases) 에서 `FP-Tester.exe` 를 받습니다
2. 더블클릭하면 검은 창이 뜨고 브라우저가 열립니다
3. 과제를 고르고 **찾기** 로 내 `.cpp` 파일을 선택한 뒤 **테스트 실행**
   (탐색기 창이 열립니다. 경로를 직접 입력해도 됩니다)

> **"Windows에서 PC를 보호했습니다" 창이 뜨면**
> 서명되지 않은 프로그램이라 나오는 경고입니다.
> **추가 정보** → **실행** 을 누르면 됩니다.
> 백신이 차단하면 예외로 등록하거나, 아래 방법으로 소스에서 실행하세요.

## macOS · Linux · exe가 안 될 때

[Python 3.10 이상](https://www.python.org/downloads/) 이 있으면 소스에서 바로 돌아갑니다.

```bash
git clone <이 저장소 주소>
cd <저장소 폴더>
python app.py
```

브라우저가 자동으로 열립니다. 안 열리면 터미널에 찍힌 주소를 직접 여세요.

소스 실행이 잘 되면 그걸로 충분합니다. 굳이 실행 파일을 만들 필요는 없지만,
원한다면 `python build_tester.py` 로 본인 OS 용 실행 파일을 만들 수 있습니다.
(Windows 는 `build_tester.bat` 더블클릭)

## 필요한 것

**C++ 컴파일러 하나.** 프로그램이 알아서 찾습니다.

| OS | 설치 |
|---|---|
| Windows | [MSYS2](https://www.msys2.org/) 설치 후 `pacman -S mingw-w64-ucrt-x86_64-gcc` |
| macOS | 터미널에서 `xcode-select --install` |
| Linux | `sudo apt install g++` |

Visual Studio 나 CLion 을 쓰고 있다면 이미 설치되어 있을 수 있습니다.

## 결과 읽는 법

```
18 / 20        컴파일 경고 없음        메모리 누수 없음
```

케이스 버튼을 누르면 그 케이스의 결과가 보입니다.

| 표시 | 뜻 |
|---|---|
| 초록 | 통과 |
| 빨강 | 출력이 다르거나, 시간 초과, 비정상 종료 |

틀린 케이스에서는 **첫 번째로 어긋난 줄**을 보여줍니다.

```
41   << 3 > 7 < 12 >>
42 − << 3 > 7 << 9 > 12 >>     내 출력
42 + << 3 < 5 >> 7 < 12 >>     정답
43   ...
```

**입력 복사** 를 누르면 그 케이스의 입력이 클립보드에 들어갑니다.
IDE 나 터미널에 붙여넣어 직접 디버깅해 보세요.

## 자주 겪는 문제

**컴파일러를 찾지 못했다고 나옵니다**
위 표를 보고 설치하세요. 설치 후 프로그램을 다시 실행해야 합니다.

**컴파일은 되는데 케이스가 전부 틀립니다**
출력 형식을 먼저 확인하세요. 공백 하나까지 정확히 일치해야 합니다.
`< 25 < 500 >>` 처럼 노드 사이 공백과 꺾쇠 위치가 규격대로여야 합니다.

**시간 초과가 납니다**
무한 루프일 가능성이 높습니다. 삭제 연산에서 부모 포인터를 갱신하지 않아
사이클이 생기는 경우가 흔합니다.

**메모리 누수가 있다고 나옵니다**
프로그램이 끝날 때 트리의 모든 노드가 해제되어야 합니다.
`delete` 를 빠뜨린 경로가 없는지 확인하세요.

**그 외**
아래를 실행하면 환경과 컴파일러 상태를 점검해 줍니다.

```
FP-Tester.exe --diagnose
```

소스로 쓰는 경우는 `python diagnose.py`.

출력 결과를 그대로 조교에게 보내주시면 원인 파악이 빠릅니다.

## 참고

- 이 채점기는 **공개 테스트케이스**로만 검사합니다. 실제 채점은 더 많은
  케이스로 이루어지므로, 여기서 전부 통과해도 만점이 보장되지는 않습니다.
- 반대로 여기서 틀리면 실제 채점에서도 틀립니다. 제출 전에 꼭 돌려보세요.
- 이 프로그램은 인터넷에 아무것도 보내지 않습니다. 전부 본인 PC 안에서 돌아갑니다.
